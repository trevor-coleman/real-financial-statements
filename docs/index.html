Real Financial Statements

Proper accounting for your transport empire, with real financial statements.

Get it on mod.io Source on GitHub

What it does

A mod for Transport Fever 3 that replaces the Finances tab of the finance window with three proper statements, built from the game's own numbers. The original table is still there as the Default tab.

Income Statement

Revenue, operating expenses, operating profit before depreciation (EBITDA), depreciation, interest and net income.

Cash Flow

Operating, investing and financing activities, net change in cash, and opening and closing cash.

Balance Sheet

Cash, vehicles, infrastructure, loans and equity as of now.

How money is treated

  • Capital expenditure never reduces operating profit. Roads, tracks, stations, depots, signals and vehicle purchases are investing cash flows, shown as a memo line on the Income Statement.
  • Loans are financing, not income. Borrowing and principal repayments appear only in financing. Interest is an expense.
  • Vehicle sales are investing inflows, netted against purchases.
  • Depreciation covers vehicles only, using the game's own depreciated value at each year-end. The game has no depreciation for infrastructure; it charges upkeep instead.
  • Sections collapse and rules mark every total, like a printed statement.

It shows its working

Each statement ends with OK / CHECK lines: net income plus investing matches the game's own "Earnings" figure, closing cash matches your bank account, and the Balance Sheet balances. If the numbers don't tie, you'll see it.

Reporting only

It never changes prices, costs, income, loans or your cash, and it never books transactions. The only thing it stores in a save is a small ledger of year-end vehicle values, used for the depreciation line.

Good to know

  • Depreciation is recorded from the start of a new game. In an existing save it appears from the second year-end onwards, and earlier years show 0 with a note.
  • The Balance Sheet shows the current position only; historical balance sheets aren't available.
  • Infrastructure is shown at cumulative construction cost, because the game doesn't expose infrastructure values.

Install

Subscribe on mod.io or through the in-game Mod Hub, enable Real Financial Statements when you start or load a game, then open Finance → Finances.
